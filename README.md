# نموذج تقييم مقابلة شخصية وفنية — ICTD

فورم HTML عام (RTL) لتقييم المقابلات الشخصية والفنية لأي مرشح، مع حفظ تلقائي في Google Sheets عبر Apps Script، ورقم مرجعي فريد لكل نموذج.

## الملفات
| الملف | الوصف |
|---|---|
| `تقييم_مقابلة_شخصية_وفنية.html` | الفورم نفسه — يُفتح مباشرة في المتصفح أو يُنشر على GitHub Pages |
| `Code.gs` | كود الخلفية (Apps Script) الذي يستقبل البيانات ويكتبها في Google Sheet |
| `CHANGELOG.md` | سجل إصدارات هذا الملف |

## خطوات الإعداد (مرة واحدة)

> ✅ تم بالفعل إنشاء الشيت في Google Drive الخاص بك:
> **"سجل تقييم المقابلات - ICTD"**
> https://docs.google.com/spreadsheets/d/1T54mh8JjtVzvYK5m7LUgy1ZClFrRZ7vQBBKiy2JZQG4/edit
>
> ✅ تم نشر الـ Web App وربط رابطه داخل الفورم بالفعل — لا حاجة لأي إعداد إضافي، الفورم جاهز للاستخدام مباشرة.

رابط الـ Web App المعتمد حاليًا (مثبّت داخل الفورم):
```
https://script.google.com/macros/s/AKfycbw4tUzulqlefBbV-6ebAzPh68iARLk18yULqU5X6o5Ai6uMe4D-5KX5GuARhj34D0gdjQ/exec
```

إذا احتجت تعديل `Code.gs` لاحقًا، يجب عمل **Deploy → Manage deployments → Edit → New version** حتى يعمل التحديث، والرابط أعلاه سيبقى كما هو ما لم تُنشئ نشرًا (deployment) جديدًا بالكامل.

> عند أي تعديل لاحق على `Code.gs`، يجب عمل **Deploy → Manage deployments → Edit → New version** حتى يعمل التحديث.

## الاستخدام لكل مقابلة جديدة
1. افتح الفورم — سيظهر **رقم مرجعي جديد تلقائيًا** أعلى الصفحة.
2. عبّئ بيانات المرشح وجدول التقييم والتوصية.
3. اضغط **"💾 حفظ في Google Sheets"** لتسجيل البيانات.
4. اضغط **"🖨️ طباعة / حفظ PDF"** لإصدار نسخة نظيفة للطباعة أو الأرشفة.
5. اضغط **"🆕 مقابلة جديدة"** لتفريغ النموذج والبدء بمقابلة أخرى دون إعادة تحميل الصفحة.

## النشر على GitHub Pages
ارفع مجلد `v1.0/` كما هو (بدون تغيير اسم الملف) إلى المستودع. اسم المجلد يحمل رقم الإصدار تمهيدًا للنشر؛ رقم الإصدار داخل الصفحة يظهر أسفل يسار الشاشة.
